# Credit Risk Assessment using Machine Learning and SHAP

An end-to-end Machine Learning project that assesses credit risk and uses Explainable AI (SHAP) to help interpret model predictions.

## 🚀 Live Demo

**Try the application:** https://credit-risk-assessment-using-shap-1.onrender.com

## 📌 Project Overview

This project combines Machine Learning and Explainable AI to assess credit risk based on input features. SHAP (SHapley Additive exPlanations) is used to understand how different features contribute to model predictions.

The application is deployed using Render and provides an interface for users to explore credit risk predictions.

## ✨ Features

- Credit risk prediction using Machine Learning
- Data preprocessing and feature engineering
- Model evaluation
- SHAP-based prediction explanations
- FastAPI backend
- Web application deployment on Render

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/Abhishekuk04/Credit-risk-assessment-using-SHAP.git
```

**2. Navigate to the project directory**

```bash
cd Credit-risk-assessment-using-SHAP
```

**3. Create and activate a virtual environment**

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

**4. Install dependencies**

```bash
pip install -r requirements.txt
```

**5. Run the application**

If the FastAPI entry point is `main.py` and the application object is `app`:

```bash
uvicorn main:app --reload
```

Open `http://127.0.0.1:8000/docs` to access the FastAPI documentation.

## 🧠 Explainable AI with SHAP

SHAP explains model predictions by estimating how individual features contribute to the output. This helps make predictions more interpretable and provides insight into the factors influencing credit risk assessments.
